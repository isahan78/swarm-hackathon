**Title:** "When the transcript lies: white-box monitoring for swarm attacks that spoof or split their logs." Track 4 (Oversight).

**Decisive discovery:** owner's ais-research repo (github.com/isahan78/ais-research,
also local at /Users/IsahanKhan/ais-research) means owner IS the interp person.
They own the full probe pipeline (experiment/: harvest_activations.py, train_probe.py,
cross_fit.py, TF-IDF text baseline, length controls, sealed pre-regs, pod_overnight.sh
on RunPod), on Qwen3-8B, and a control env (goodhart-prep/: agent + hidden shortcut +
L0-L3 tamper-detecting grader). Plus J-lens sprint plan. MATS 12.0 Neel Nanda applicant.

**The crux (owner's own null reframes the project):** owner's "Probe-Text Gap" result
shows a linear probe NEVER beats a bag-of-words reader of the SAME trace, because
activations at a cut are a deterministic function of the prefix tokens. So white-box
only earns its keep when the transcript is UNFAITHFUL to the computation. That is exactly
the swarm regime: HF incident agents SPOOFED transcripts (spread to 7%); Kitaoka's split
attack makes each transcript individually innocent (85%->7%). Owner's null = the control
and launchpad, not a wall.

**Experiment:** Qwen3-8B on RunPod. Extend goodhart-prep to agent + benign task + hidden
side objective. Two monitors race every condition: black-box transcript reader (owner's
text baseline / LLM judge) vs white-box linear probe for "pursuing the hidden objective."
Realizability rule carries over: monitor sees only the public/spoofable transcript, never
true CoT. Three conditions ordered by transcript faithfulness:
  1. Honest single agent -> probe ties/loses (anchor: probe 0.67-0.76 vs text 0.74-0.82).
  2. Spoofed single agent (HF move) -> text degrades, probe holds.
  3. Distributed swarm (split task, per-agent transcript) -> text craters (~7%), probe only reader left.
Money plot: detection at matched FPR, both monitors, across the 3 conditions; the result
is the crossover point. Can't-lose: any outcome is a real finding.

**Scope:** FLOOR (Sat, all owner's own tools) = conditions 1+2, single agent, no multi-agent
code. CEILING (Sun, needs recruit) = condition 3, the swarm, makes it Track-4 load-bearing.

**Team:** owner owns probe+harness+analysis+writeup (the hard 80%). RECRUIT = ONE multi-agent
orchestration person (agents messaging each other + shared board log) — owner's only real gap,
