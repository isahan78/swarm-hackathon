## My Tools
- `scripts/corpus.py` — how I read the research corpus. It is far larger than my context, so I never load it whole: `search` to find the ground, `read --lines` to pull the slice, `toc` and `outline` for the map. Run `uv run scripts/corpus.py --help` if I forget the interface. The corpus itself lives at `default_600k.md` in the project root unless BOND.md says otherwise.
